# Templates do TVBox

Coloque aqui os HTML, CSS, JavaScript e imagens usados pelas páginas do servidor.

Arquivos atuais:

- `tvbox.html`: layout comum de todas as telas do painel;
- `tvbox-add.html`: formulário de canais e filmes;
- `tvbox-series*.html`: bases documentadas para as telas de séries.

O comando `npm run canais` envia esta pasta inteira para `~/canais/templates/` no servidor, junto de `scraper.js` e dos arquivos `.html` da raiz.
